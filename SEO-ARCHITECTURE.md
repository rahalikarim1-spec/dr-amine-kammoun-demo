# SEO Architecture — Dr Amine Kammoun (FR / AR)

> Source of truth: `src/lib/registry.ts` (structure) and `src/content/{fr,ar}/` (copy).
> The inventory table below is **generated** — run `npm run docs:seo` after changing the registry.
> Audit tooling: `npm run validate` (sources) and `npm run validate:html` (after build).

## 1. Principles
- **One URL = one search intent.** Overlapping topics were merged instead of duplicated:
  - "Échographie grossesse" → merged into **Échographie obstétricale** (same intent).
  - "Échographie 3D" + "4D" → one page **Échographie 3D/4D**.
  - *Douleurs pelviennes*, *Ménopause*, *Troubles menstruels* have **one canonical page** under Gynécologie; the Pathologies hub cross-lists them (`alsoInHubs`) instead of duplicating.
- **Local SEO = one strong page** (`/fr/gynecologue-ain-zaghouan-nord/`) + one small hub (`/fr/zones-desservies/`) with genuinely useful per-area content (a Google Maps itinerary computed *from* each area). No doorway pages per district.
- **Topic clusters:** 5 hubs (Gynécologie, Grossesse, Échographie, Fertilité, Pathologies) → children → grandchildren (e.g. trimesters under *Suivi de grossesse*, frottis under *Dépistage*).
- **Bilingual:** `/fr/…` (fr-TN, LTR) and `/ar/…` (ar-TN, RTL), full 1:1 parity, hreflang `fr-TN`, `ar-TN`, `x-default` (→ FR). Arabic slugs are Latin transliterations (stable, readable); they can be switched to Arabic script in the registry if desired.
- **Keyword data** (only the volumes supplied): "gynécologue lac 2" 100–1K → addressed on the local page, Lac 2 / Berges du Lac section and the areas hub; "gynécologue l'aouina", "gynécologue soukra", "gynécologue obstétricien tunis", "PMA Tunisie" 10–100 each → local page, areas hub, home, PMA page (title "PMA en Tunisie…"). No other volume is claimed.
- **Indexing switch:** `NEXT_PUBLIC_INDEXING=on` is required for `index` + permissive `robots.txt`. Default is **closed** (demo).
- **FAQPage JSON-LD is OFF** (`seoConfig.enableFaqSchema`): Google limits FAQ rich results to authoritative government/health sites. FAQs stay visible in the page.
- **Structured data:** `WebSite`, `Physician`, `MedicalClinic`, `WebPage` / `MedicalWebPage` / `ContactPage`, `BreadcrumbList`. Never ratings, reviews, awards or credentials. `reviewedBy`/`lastReviewed` only appear when `editorialConfig.reviewed = true`.
- `noindex`: privacy and cookies pages (boilerplate). They are excluded from the sitemap.
